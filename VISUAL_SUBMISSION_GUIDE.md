## 💡 Quick Tips

### Before Submitting
```
✅ DO:
- Read assignment instructions
- Check file format
- Verify file size < 10MB
- Preview your work
- Submit early

❌ DON'T:
- Wait until last minute
- Submit wrong file
- Forget to click Submit
- Use unsupported formats
```

### File Types
```
✅ Supported:
📄 Documents: PDF, DOC, DOCX, TXT
📊 Spreadsheets: XLS, XLSX
📽️ Presentations: PPT, PPTX
🖼️ Images: JPG, PNG, GIF
📦 Archives: ZIP

❌ Not Supported:
EXE, BAT, SH (executables)
Files over 10MB
```
